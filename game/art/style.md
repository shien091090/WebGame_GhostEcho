# GhostEcho 美術規格 v3

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文在 file:// 下會變亂碼。
> art.js 以一般 `<script src>` 載入(非 module), 載入後取用 `window.Art`。

## 邏輯畫布尺寸

- 1280 x 720 px(`Art.canvas`)。上方資訊列 y 0~80, 關卡區 y 80~720(40 欄 x 20 列, 格 32 px)
- **所有物件 state 的位置一律用格座標**(x = 欄方向的連續值, h = 高度, 角色 / 幽靈為腳底中心), 換算由 art.js 做:
  - 像素 x = x * 32;  像素 y = 80 + (18 - h) * 32(h=-2 → 畫面底 720, h=18 → 關卡區頂 80)
  - `Art.grid.toX(x)` / `Art.grid.toY(h)` 可直接用(RD 若要自己畫除錯線)
- 會動的函式(閃爍、虛線流動)讀 `state.t`(秒)。請傳**會被暫停凍結的遊戲時鐘**, 暫停與說明時畫面跟著靜止

## 形狀語言

扁平、圓角、無貼圖; 「能操作的」是實心(角色), 「重播」是半透明 + 細描邊(幽靈), 地形是平塗方塊加亮邊; 危險一律紅、鉤爪一律洋紅、可踩的面一律亮色上緣。

## 理念落實

- P0 辨識度先於好看: 角色(實心琥珀)與幽靈(半透明青)用同一個剪影, 只靠材質與顏色分「我」與「重播」, 一眼不會認錯誰是能操作的那個
- P1 視覺權重跟著決策迫切度: 最亮的元素只留給要做決定的東西 — 幽靈頭頂平台(白光)、可鉤框(洋紅光)、伸出的尖刺(紅); 背景格線與地形紋最暗
- P2 規則上存在的東西畫面上就存在: 幽靈頭頂平台只在站立幀畫出、寬度正好 1 格(= 落腳容差); 收起的尖刺仍畫底座與矮刺尖, 收起時也看得出哪裡有陷阱; 「四個鉤中條件都成立」畫成可鉤框; 資訊列常駐列出 X / R / B / H / Esc
- P3 一個意義一種長相: 頭頂白光 = 可踩、洋紅 = 鉤爪、紅 = 會死、綠 = 終點與成功; 說明頁全部直接呼叫遊戲內函式, 標題畫面的站立幽靈也帶頭頂平台
- P4 關鍵區分走兩條通道: 站立 vs 騰空 = 頭頂平台有無 + 腳的姿勢(站直 / 收起); 角色 vs 幽靈 = 顏色 + 實心 / 半透明; 尖刺收起 vs 伸出 = 高度(5px vs 30px)+ 顏色(暗紅 vs 亮紅); 即將消失 = 變灰 + 閃爍
- P7 每個元素都要掙得版面: 資訊列只放關卡序號、角色序號與可用按鍵, 不放錄影剩餘時間或計時(規格也不做); 角色身上不標序號(資訊列已有)
- P9 以最混亂的那一刻驗收: 截圖驗收用第 3 關「幽靈可鉤 + 角色拉動中 + 另一幽靈即將消失 + 尖刺伸出 + 待命提示」同框
- P13 事件要排隊: 本作沒有事件演出; 死亡只換角色外觀, 換人延遲期間不疊任何提示
- P15 回饋強度與事件份量成正比: 只有過關(角色綠光 + 旗面轉亮打勾)有發光演出, 死亡只褪色倒地
- P17 進度類圖形與數字分工: 本作沒有進度圖形(錄影剩餘時間規格不做), 不適用
- P18 重要資訊不只存在一瞬間: 角色序號常駐資訊列; B 退回後序號直接改成新值
- P19 資訊貼著物件: 可踩、可鉤、即將消失都長在幽靈本體上(頭頂平台、四角框、本體閃爍), 不另掛標籤; 待命提示貼在出生點上方
- P21 示意圖要選對錯會分岔的例子: 說明頁第 3、5、6 頁都是打勾 / 打叉並排, 兩格只差規則分界那一項(收起 vs 伸出、幽靈站著 vs 跳起、空中 vs 地上)

## 物件表

| 物件 | 函式 | state 欄位 | 各狀態視覺差異 |
|---|---|---|---|
| 背景 | `drawBackground(ctx)` | - | 深色漸層 + 關卡區淡格線 |
| 地面 / 柱 / 平台 / 矮樁 | `drawTerrain(ctx, s)` | `cols`: 長度 40 陣列, 每欄地表 h(可半格)或 `null`(坑) | 同高相鄰欄合成一塊; 地表 4px 亮邊; 外露牆面 3px 稍亮邊; 內部淡格紋 |
| 坑 | `drawPit(ctx, s)` | `cols`: 同上, 畫所有 `null` 欄 | 由鄰欄地表往下漸暗, 畫面底 46px 紅色漸層 + 3px 紅線(掉下即死) |
| 尖刺陷阱 | `drawSpikeTrap(ctx, s)` | `col`, `h`(該欄地表), `out`: bool | 共通: 地表上的金屬底座 + 紅細線。收起(`out:false`): 三根 5px 暗紅矮刺尖, 讀成可站; 伸出(`out:true`): 三根亮紅尖刺填滿尖刺格(地表~地表+1)+ 格內淡紅底 |
| 出生點 | `drawSpawn(ctx, s)` | `x`, `h` | 固定: 琥珀色低不透明拱門 + 地面短線 |
| 終點旗 | `drawGoalFlag(ctx, s)` | `col`, `h`(該欄地表), `reached`: bool, `t`? | 未到達: 綠旗, 輕微飄動; 已到達: 旗面轉淡綠亮色 + 打勾 + 綠色光暈, 不飄 |
| 角色 | `drawPlayer(ctx, s)` | `x`, `h`, `status`: `'idle'`/`'active'`/`'pulled'`/`'dead'`/`'goal'`, `facing`: 1/-1, `air`?: bool(騰空收腳), `anchor`?: {x,h}(pulled 時傳錨點), `t`? | idle(待命): 閉眼 + 外圍琥珀虛線框緩慢流動; active: 睜眼朝 facing, `air` 時收腳; pulled(被鉤爪拉動中): 洋紅描邊、身體朝錨點傾斜、背後速度線; dead: 橫躺、褪色、叉眼(畫在腳底位置); goal: 開心眼、舉手、綠光 |
| 幽靈 | `drawGhost(ctx, s)` | `x`, `h`, `phase`: `'play'`/`'fading'`/`'gap'`, `grounded`: bool(該幀為「站立」), `hookable`: bool, `expiring`: bool, `fade`: 0~1, `facing`, `t`? | 見下方幽靈狀態對照 |
| 鉤爪索 | `drawHookRope(ctx, s)` | `x`, `h`(角色腳底), `ax`, `ah`(錨點), `active`?: bool(預設 true) | 拉動中: 洋紅亮線(深色襯底)從角色胸口連到錨點, 錨點畫三爪 + 白點; 無: 不呼叫或 `active:false` |
| 待命提示 | `drawStandbyHint(ctx, s)` | `visible`: bool, `x`, `h`(出生點) | 顯示: 出生點上方深底琥珀框「按移動或跳躍開始」(會夾在畫面內); 隱藏: 不畫 |
| 關卡序號 + 角色序號(資訊列) | `drawHud(ctx, s)` | `level`: 1~4, `runner`: 1~3, `hookEnabled`: bool(第 3 關起 true) | 左「第 n 關」; 角色序號晶片「角色 n/3」; 右側可用按鍵(hookEnabled 時多 X 鉤爪) |
| 標題畫面 | `drawTitleScreen(ctx, s)` | 無(傳 `{}`) | GhostEcho + 殘影; 小景; Enter 開始、1~4 直接選關 |
| 說明畫面 | `drawGuidePage(ctx, s)` | `page`: 1~8(`Art.guidePageCount` = 8) | 不透明整頁: 標題、一句說明、示意圖、← → 翻頁 / Enter 關閉、頁碼 n / 8 |
| 暫停畫面 | `drawPauseScreen(ctx, s)` | 無 | 遮罩 + 面板: Esc 繼續 / N 放棄本關 / H 說明。畫在遊戲畫面之上 |
| 自評畫面 | `drawRatingScreen(ctx, s)` | `level`: 1~4 | 遮罩 + 面板「第 n 關 過關」, 三個選項同樣式(不標示哪個較好)+ Enter 跳過 |
| 結束畫面 | `drawEndScreen(ctx, s)` | 無 | 整頁: 4 關都走完了 / 謝謝試玩 / Enter 回標題 |

### 幽靈狀態對照(RD 傳值方式)

| 規格狀態 | 傳入 | 外觀 |
|---|---|---|
| 站立(頭頂可踩) | `phase:'play', grounded:true` | 半透明青本體 + 頭頂白色發光平台(32 x 6, 頂面 = 腳底 + 2 格) |
| 騰空 | `phase:'play', grounded:false, hookable:false` | 半透明青本體, 收腳, 無頭頂平台 |
| 騰空且可鉤 | `phase:'play', grounded:false, hookable:true` | 同騰空 + 洋紅四角框(貼著身體外緣, 帶洋紅光) |
| 即將消失 | 上面任一種再加 `expiring:true` | 本體轉灰藍並以 4 Hz 閃爍; 頭頂平台與可鉤框照常畫、不閃(仍可踩、可鉤) |
| 淡出 | `phase:'fading', fade:0→1` | 灰色虛線外框, 隨 fade 淡到看不見; 不畫頭頂平台、不畫可鉤框 |
| 空檔 | `phase:'gap'` | 不畫 |

- `hookable` 請只在第 3 關起、且四個鉤中條件此刻全成立時給 true; `grounded:true` 時 hookable 會被忽略
- 被鉤爪拉動中的角色: `drawPlayer` 傳 `status:'pulled'` + `anchor`, 同時呼叫 `drawHookRope`

## 說明頁示意圖(drawGuidePage)

- 共 8 頁, 圖裡所有物件直接呼叫遊戲內函式; 地形一律平地(第 2 頁有一個 2 欄小坑), 不畫任何一關
- 1 目標: 整個遊戲畫面縮圖, 平地、左出生點、右終點旗, 資訊列「角色 1/3」用虛線圈起
- 2 移動: ← → 雙向箭頭與按鍵帽, 角色在空中越過小坑, 虛線跳躍弧(照規格跳躍物理)+ 空白鍵
- 3 換人: 三格。收起尖刺上站著 ✓ / 走進(虛線箭頭)伸出的尖刺倒下 ✗ / 出生點待命的下一名 + 「角色 2/3」
- 4 幽靈: 角色 2 在出生點待命; 幽靈沿「走 → 跳 → 走」的虛線路線, 末端大弧線接回起點; 右上小圖「角色 3/3」只看到角色 2 的幽靈 ✓、角色 1 的 ✗
- 5 踩頭: ✓ 角色站在站立幽靈頭頂, 兩條高度線「地上起跳」(3.5)/「頭頂起跳」(5.5); ✗ 幽靈跳起中(無頭頂平台), 角色往下掉
- 6 鉤爪: ✓ 幽靈在斜上方空中(可鉤框), 鉤爪索把角色往上拉, 再接一道空中跳虛線 + 空白鍵; ✗ 幽靈站在地上, 按 X 沒有線
- 7 重來: R 格「3/3 → 3/3」, 倒地角色回到出生點, 幽靈(角色 2)原地不變; B 格「3/3 → 2/3」, 角色 2 的幽靈 ✗ 換成角色 1 的
- 8 其他按鍵: 遊戲畫面縮圖 → Esc → 暫停畫面縮圖; 遊戲畫面縮圖 → H → 說明畫面縮圖(縮圖內的按鍵由畫面自己顯示)

## 給 RD 的備註

- 資訊列右側常駐列出可用按鍵(X 只在第 3 關起顯示)。這是按鍵提示, 不含路線或策略; 若製作人判定它屬於規格「不做關內教學提示」, 傳 `hookEnabled` 照舊、改由美術拿掉該列即可
- 角色掉坑死亡時腳底已在畫面外, `dead` 狀態不必特別處理
- 終點旗高度 2 格: 第 4 關 C 地表 16 上方只剩 2 格, 畫 3 格會被資訊列蓋住
