## 鬼影回聲 數值評估(概念階段,第 1 回合)

已讀: E:\Project\Game\WebGame_GhostEcho\concept.md
概念文件沒有任何數字。下面的推算都用一組假設基準:跳躍高度 H=3.5 格,角色身高 h=2 格,走速 6 格/秒,畫面 60fps。這組基準要靠試玩校正。

---

### (1) 循環要成立需要的參數

| 參數 | 建議區間 | 說明 |
|---|---|---|
| 角色數 N | 固定 3 | 概念已定。決定每一輪試錯最多要花多少時間 |
| 跳躍高度 H | 3~4 格 | 所有高度門檻都從它推出來 |
| 幽靈可踩高度 h(頭頂到腳底) | 1.5~2 格 | 站在靜止幽靈頭上可達 H+h |
| 高度分層安全邊距 | ≥0.5 格 | 每層門檻和下一層可達高度之間留的空隙,避免沒用幽靈也勉強跳得上去 |
| 錄影長度上限 T_max | 20~30 秒 | 超過上限就強制結束這條命。回放循環週期 T 等於錄影長度,沒有上限的話可以無限拉長(見崩壞點) |
| 循環間隔 gap | 0.5~1.0 秒 | 回放結束後先淡出,再從頭播 |
| 回放起點對齊 | 新角色出生那一幀 | 第一輪相位是確定的,關卡才能用設計去保證 |
| 鉤爪射程 R | 4~6 格 | 太長的話,幽靈任何位置都能被利用 |
| 鉤爪判定窗 w | 300~450ms(建議整段上升期) | 最敏感的參數,見第 2 點 |
| 鉤爪拉升量 | 讓最高點落在 1.5H~2H | 不能和踩頭疊加到超出關卡高度 |
| 速度繼承 | 只繼承垂直速度,或完全不繼承 | 站在幽靈上時它平移,要不要帶著玩家走 |
| 重來粒度 | 可以回到「目前角色」重來,不是只能整關重來 | 決定失敗一次的成本 |
| 自毀鍵 | 有 | 把第一名角色的錄影長度從「走到坑邊」縮成「到位就結束」 |

### (2) 最敏感參數: 鉤爪判定窗 w(與循環週期 T 連動)

推算:
- 失敗成本的期望值 ≈ T / p,其中 p 是單次嘗試成功率。錯過一次就要等幽靈繞完一整圈。
- 玩家的預判節奏誤差假設 σ≈60ms(常態分佈),p = P(|誤差| < w/2):
  - w=100ms: p=P(|z|<0.83)≈0.59
  - w=150ms: p≈0.79
  - w=300ms: p≈0.99
- 用 T=15 秒代入,期望等待:w=100 約 25 秒,w=150 約 19 秒,w=300 約 15 秒。
- w 從 150 降到 100 只少了 50ms,單一操作點的耗時卻增加 32%。一關有 2~3 個這種點時會連乘,整關失敗率差距更大。p 是常態分佈累積函數,在 w≈2σ 附近最陡,所以 w 比 T 敏感。T 只是線性放大成本。
- 建議 w 至少 2.5σ(約 150ms 以上);入門關直接開成整段上升期(H=3.5 時約 0.4 秒)。

### (3) 目標單局時長

這裡的「單局」定義為一關。

| 段落 | 推算 | 時長 |
|---|---|---|
| 角色 1(錄影) | 關卡寬 40~60 格 ÷ 6 格/秒 ≈ 7~10 秒,加跳躍和到位,有自毀鍵 | 10~15 秒 |
| 角色 2 | 移動 7~10 秒,加等幽靈相位(平均 T/2≈6 秒),加重試(T/p-T≈4 秒) | 15~25 秒 |
| 角色 3 | 同上 | 15~25 秒 |
| 一次成功跑完 | | 40~65 秒 |
| 新手完整跑幾輪 | 假設 2~4 輪(第一名角色沒預判到後面需要什麼) | |

建議目標:
- 設計者自己通關 30~45 秒
- 新手中位數 2~3 分鐘
- 超過 5 分鐘視為過難

Demo 做 5~6 關,總長約 12~18 分鐘。

### (4) 預見的崩壞點

1. **靜止幽靈讓節奏判定失效**:第一名角色到位後原地不動 20 秒再自毀,幽靈在一個循環裡有 90% 以上的時間都是固定平台,鉤爪和踩頭都不用抓時機。對策:錄影上限 T_max,或規定靜止段不可踩(要不要這樣做由設計決定)。
2. **每多一代可達高度就疊加一次**:
   - 角色 1 可達 H=3.5 格
   - 角色 2 踩在跳到最高點的幽靈 1 頭上再跳,可達 2H+h=9 格
   - 角色 3 用幽靈 2 的位置錄影(回放的是位置,不受幽靈 1 消失影響),可達 3H+2h=14.5 格

   關卡高度低於 14.5 格時,角色 3 可能跳過設計好的路線。再疊上鉤爪拉升,上限會更高。關卡要按代數分出 3.5 / 9 / 14.5 三層,每層之間留 0.5 格邊距。
3. **循環重置時角色瞬移**:玩家站在幽靈頭上時,幽靈回到出生點,玩家會懸空墜落,而且每 T 秒發生一次。需要重置前的預告(對應循環間隔 gap)。
4. **預判失敗只能整關重來**:失敗一次的成本是 T1+T2+T3≈50 秒,三次就是 150 秒。如果可以從目前角色重來,三次約 60 秒。重來粒度直接決定新手時長會不會超過 5 分鐘。
5. **意外死亡浪費角色**:第一名角色開局 2 秒就掉坑,得到一個沒用的幽靈,可用角色剩 2 名。如果意外死亡率超過 30%,實際平均輪數會高於 4。
6. **錄位置還是錄輸入**:如果回放的是輸入,浮點誤差會讓軌跡漂移。必須錄每幀位置,60fps×30 秒=1800 幀,資料量不是問題。

### (5) 推算依賴的假設與埋點

假設清單:
- A1 角色 1 的錄影 10~15 秒
- A2 節奏誤差 σ≈60ms
- A3 等相位的時間 ≈ T/2
- A4 新手要跑 2~4 輪
- A5 意外死亡率 ≤30%
- A6 玩家不會大量濫用靜止幽靈
- A7 實際可達高度符合 kH+(k-1)h

逐步紀錄(每一條角色命一筆):

| 欄位 | 記錄時機 | 用來校正哪個假設 |
|---|---|---|
| 關卡、輪次、角色序號 1~3 | 角色出生 | 全部分組用 |
| 存活時長(出生到死亡或到終點) | 死亡、到終點 | A1、第 3 點的時長表 |
| 死因(坑/陷阱/自毀/錄影上限) | 死亡 | A5 |
| 死亡座標、死前最後一次輸入距死亡的秒數 | 死亡 | A5(直接衝進坑算刻意,掉落中還在操作算意外) |
| 錄影中零輸入的總秒數、最長連續靜止秒數 | 死亡 | A6 |
| 互動事件:類型(踩頭/鉤爪)、成功與否、時機偏差(ms,距判定窗中心)、當下幽靈在循環中的相位 | 每次按鉤爪、每次落到幽靈頭上 | A2(用偏差算實測 σ)、第 2 點的 p |
| 到達互動點後到第一次成功互動的等待秒數 | 第一次成功互動 | A3 |
| 這條命經過幾次循環 | 死亡、到終點 | A3、T/p 成本 |
| 最高到達高度(格)、是否經過非預期路線 | 死亡、到終點 | A7、崩壞點 2 |
| 循環重置時站在幽靈上而墜落的次數 | 循環重置 | 崩壞點 3 |

逐局紀錄(每關一筆):

| 欄位 | 記錄時機 | 用來校正哪個假設 |
|---|---|---|
| 這關總耗時、跑了幾輪 | 通關或放棄 | A4、目標時長 |
| 每輪結果(通關/三名都死/主動重來)、重來發生在第幾名角色 | 每輪結束 | A4、崩壞點 4 |
| 是否放棄這關、放棄前耗時 | 離開關卡 | 5 分鐘過難線 |
| 通關時用了幾名角色 | 通關 | 確認有沒有關卡能被少用角色跳過(A7) |

試玩後先用互動事件的時機偏差算出實測 σ,再重算 p 與單一操作點的耗時;σ 實測超過 80ms 的話,w 要再加寬。最終要不要採用由你決定。
