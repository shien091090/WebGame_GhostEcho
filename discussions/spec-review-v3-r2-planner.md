## 規格審查第 2 回合: 回應分歧與追問

結論: 第 3 關的問題光調地形分不開, 我建議改用尖刺時機約束; 預期解餘量我改成接受交給 RD 調, 但自動驗證要加一條餘量檢查。

### 分歧 A: 第 3 關直覺亂跑會錄出正確幽靈
我維持第 1 回合的判斷, 理由比上回更強: 預期解裡角色 1 的輸入本來就是「全速走出坑邊、落上矮樁、跳」, 和走錯一步的直覺路線完全一樣, 不是「容易混淆」, 而是同一組輸入。數值建議把矮樁左移 1 欄: 這能把走出坑邊的落點餘量從 0.04 拉大, 解掉他提的窗口問題, 但直覺落上矮樁也會更容易, 這條漏洞不會變小, 只會變大。所以那一欄要不要移, 要等追問 1 的改法定案後再決定。

### 分歧 B: 預期解餘量不足 0.5 格
我改立場, 接受交給 RD 在可調範圍內逐幀調整, 原因是數值說整體結構可行, 手算本來就收斂不了。條件是自動驗證的通過條件要補一條「預期解每段落地的水平與高度餘量 ≥ 0.5 格」: 目前的通過條件只看有沒有過關, 第 2 關餘量 0.2、第 3、4 關落上矮樁餘量 0.04 這種情況都會被判通過。第 4 關角色 3 那段例外, 規格要先改: 它不只是餘量小, 而是依賴目前沒有定義的角落碰撞規則, 輸入序列要改成「中心 x 到 18.0 放 →」。我同意數值的另一點: 驗證時用 0.1 格掃整個站立面、取最小窗口。

### 追問 1: 第 3 關的具體改法
1. **光調地形分不開**: 在高度 1 的地面上全速起跳, 落點會連續覆蓋 x 約 9~16, 矮樁不管放哪裡、多高, 都有直覺跳法落得上去; 調距離或高度只會連預期解一起擋掉。
2. **我接受改用時機約束, 可直接放進規格的條目如下**: 「第 3 關坑邊欄 9 併入尖刺走廊(欄 4~9 同相位), 角色 2 只能在尖刺收起時站在坑邊鉤爪; 幽靈 1 從矮樁起跳的時刻要落在收起 6~8 那一窗之前約 0.2~1.0 秒(企劃初值, 由 RD 驗算), 也就是角色 1 要在矮樁上等過一次伸出。直覺路線『2.0 起步、落上矮樁就跳』產生的幽靈, 角色 2 能鉤的時段要 < 0.3 秒, 這條列為新捷徑『直覺落上矮樁即跳』交 RD 掃描, 掃描範圍要包含角色 2 從欄 3 起跳後在空中鉤。」
3. 附帶好處: 坑型刻意死亡的判準可以從「矮樁站立 ≥ 0.2 秒」提高到「≥ 1.0 秒」, 和走錯一步落上矮樁的 0.2~0.5 秒能乾淨分開, 這個指標會比現在可信。
4. 代價: 教鉤爪的這一關多了時機負擔, 第 3、4 關的難度坡度會被壓平, 時長也會往上偏, 需要數值重算。
5. 如果你不想在教學關加時機, 替代做法是: 把「第 3 關直覺可過」記成已知取捨, 第 3 關的坑型死亡從刻意死亡率剔除、只當診斷, 驗證改靠第 2、4 關。

### 追問 2: 可直接放進規格的規則文字
- **角落碰撞**: 下落中身體與地形重疊、但腳底中心不在該地形欄時, 把角色水平推回腳底中心那一側直到不重疊, 垂直照常下落(貼牆滑下, 不站上去)。
- **同一幀按空白鍵與 X**: 先處理 X; 鉤中時這次空白鍵作廢、保留鉤後那一次空中跳, 落空時照常處理跳躍。
- **拉動中按跳躍**: 拉動中新按下的空白鍵會被保留, 拉動結束那一幀空白鍵仍按住就立刻執行鉤後空中跳; 拉動中已放開就作廢。
- **站在移動幽靈上按 ← / →**: 站在幽靈頭頂時, 角色每幀的水平位移 = 幽靈該幀的水平位移 + 玩家方向鍵造成的走速位移, 兩者相加。
- **暫停凍結範圍**: 暫停與說明畫面開著時, 遊戲內所有計時一律凍結(幽靈、尖刺、錄影、存活、待命、換人延遲、鉤爪拉動), 也不計入關卡總耗時。
- **各畫面按鍵**: 暫停中只受理 Esc(繼續)、N(放棄)、H(開說明, 關掉後回暫停畫面); 說明中只受理 ← / → / Enter, Esc 無效; 自評畫面只受理 1 / 2 / 3 / Enter, Esc 與 H 無效。

### 追問 3: 埋點與排除規則
- **困在死路上被刺死**: 命紀錄加一欄「在該設計死亡點停留期間的起跳次數」, 刻意死亡率另外算一版只計起跳次數為 0 的死亡; 試跳過、跳不上去才放棄的, 視為困住而不是算準時機。
- **選關跳過教學**: 關卡紀錄加一欄「進關方式(依序 / 標題選關)」, 所有驗證指標只計依序進入的局, 選關的局只當診斷。
