# 埋點規格 v1

## 檔案與下載
每局結束自動下載 JSON, 檔名 gamelog-WebGame_GhostEcho-<YYYYMMDD-HHMMSS>.json
- 一局 = 一關。過關(自評選完或跳過後)或暫停中放棄本關時下載一次; 中途關閉頁面不下載
- 檔案內容: 本關的事件列表(依發生順序)+ 每條命一筆的命紀錄 + 本關逐局彙整
- 名詞依 spec.md v1: 出生 = 待命後第一次按移動或跳躍; 互動點、設計死亡點、各關分層見 spec.md「規則」各關地形表

## 事件
| 事件 | 何時記 | 欄位 |
|---|---|---|
| 角色出生 | 每名角色出生時 | 關卡、輪次、角色序號(1~3) |
| 互動 | 每次按 X(第 3 關起)、每次角色落到幽靈頭頂 | 類型(踩頭 / 鉤爪)、成功與否、鉤爪按下時幽靈已騰空秒數、當下幽靈在循環中的相位 |
| 命結束 | 角色死亡、到終點、被 R / B 作廢、本關被放棄 | 存活時長、死因、死亡座標、死前最後一次輸入距死亡秒數、錄影中零輸入總秒數、最長連續靜止秒數、到達互動點到第一次成功互動的等待秒數、這條命經過幾次幽靈循環、最高到達高度(格)、是否經過非預期路線、循環重置時站在幽靈上而墜落的次數、幽靈在需要點的停留秒數、角色 2/3 到達需要點時與幽靈的相位差、死亡位置是否落在設計死亡點、與最近需要點的距離 |
| 重來 | 自動重錄角色 3、按 R、按 B | 種類(自動重錄角色 3 / 重錄這一名 / 退回上一名)、發生在第幾名角色; 退回上一名時另記退回到第幾名 |
| 過關 | 角色碰到終點旗 | 通關時用了幾名角色 |
| 自評 | 自評畫面按下 1 / 2 / 3 / Enter | 過關自評(碰運氣 / 試了幾次才想通 / 一開始就規劃好 / 跳過) |
| 放棄 | 暫停中按 N | 是否放棄這關、放棄前耗時 |

欄位定義:
- 成功與否: 鉤爪 = 鉤中; 踩頭 = 落上後從幽靈頭頂起跳離開為成功, 因幽靈騰空或淡出而掉下為失敗
- 鉤爪按下時幽靈已騰空秒數: 幽靈這段騰空從起點到按下的秒數; 幽靈未騰空、踩頭事件時為空
- 幽靈在循環中的相位: 本圈已播放秒數 ÷(幽靈錄影長度 + 淡出 0.75 秒), 0~1
- 存活時長: 出生到命結束的秒數
- 死因: 坑 / 陷阱 / 錄影上限; 命不是因死亡結束時為空
- 死亡座標: 死亡當幀角色中心 x 與腳底高度 h(格, 小數一位); 非死亡結束時記結束當下位置
- 死前最後一次輸入距死亡秒數: 最後一次按下或放開 ←、→、空白鍵、X 到死亡的秒數
- 錄影中零輸入總秒數: ←、→、空白鍵、X 都沒按住的累計秒數
- 最長連續靜止秒數: 角色位置不變的最長連續秒數
- 到達互動點到第一次成功互動的等待秒數: 首次進入任一互動點範圍, 到第一次成功踩頭或鉤中的秒數; 沒有成功互動為空
- 這條命經過幾次幽靈循環: 這條命期間幽靈回到第 0 幀的次數
- 最高到達高度: 這條命腳底最高的 h
- 是否經過非預期路線: 首次站上該關某一分層地表(第 1 關高台; 第 2 關 B、C; 第 3 關對岸; 第 4 關 B、C)時, 最近一次成功互動不是發生在該層指定的互動點, 或沒有互動 → 是
- 循環重置時站在幽靈上而墜落的次數: 角色站在幽靈頭頂時幽靈進入淡出的次數
- 幽靈在需要點的停留秒數: 這條命在停留型互動點(1-刺區、2-柱、2-刺區、4-柱)上的累計站立秒數, 分點記; 這段停留即下一名看到的幽靈停留時間
- 角色 2/3 到達需要點時與幽靈的相位差: 角色首次進入某停留型互動點的時刻 − 幽靈本圈首次進入同一點的時刻(秒; 負值 = 比幽靈早到; 幽靈本圈未進過為空)
- 死亡位置是否落在設計死亡點: 只記角色 1、2; 依 spec.md 各關「設計死亡點」範圍判定
- 與最近需要點的距離: 只記角色 1、2; 死亡座標到最近互動點範圍邊緣的格數, 在範圍內為 0

## 逐局彙整
| 欄位 | 怎麼算 |
|---|---|
| 關卡 | 1~4 |
| 這關總耗時 | 進關到過關或放棄的秒數, 不含暫停與說明畫面 |
| 跑了幾輪 | 本關最大輪次 |
| 每次重來的種類與發生在第幾名角色 | 依序列出所有「重來」事件的種類與名次; 另按種類 × 名次計次 |
| 是否放棄這關 | 有「放棄」事件為是 |
| 放棄前耗時 | 放棄時的這關總耗時; 未放棄為空 |
| 通關時用了幾名角色 | 過關事件的值; 放棄為空 |
| 過關自評 | 自評事件的值; 放棄為空 |
| 「退回上一名」使用次數 | 種類為退回上一名的重來事件數 |
| 退回到第幾名 | 每次退回上一名的「退回到第幾名」依序列出 |
| 角色 1、2 死在設計死亡點的比例 | 角色序號 1、2 且死因不為空的命中, 落在設計死亡點的比例; 另列與最近需要點距離的平均 |
| 各輪角色 1 路線變化 | 依輪次列出每輪最後一條角色 1 命的死亡座標與存活時長; 相鄰兩輪的死亡座標距離(格)與存活時長差(秒) |

## 驗證指標
門檻為企劃初始提議, 待製作人定。

| 指標 | 計算 | 門檻 |
|---|---|---|
| 規劃型自評比例 | (試了幾次才想通 + 一開始就規劃好)÷ 非跳過的自評數, 分關看 | ≥ 60%, 且「碰運氣」≤ 30% |
| 退回上一名使用率 | 第 2、4 關中至少退回一次的局數 ÷ 該關局數 | ≥ 40% |
| 刻意死亡率 | 全部局的角色 1、2 死在設計死亡點的命數 ÷ 角色 1、2 死亡命數 | ≥ 70% |
| 角色 1 路線收斂 | 跑了 3 輪以上的局中, 最後兩輪角色 1 死亡座標距離 ≤ 2 格且存活時長差 ≤ 2 秒的局數比例 | ≥ 50% |

## 數值假設對照
| 假設 | 用哪些欄位校正 |
|---|---|
| 角色 1 錄影 10~17 秒、各段時長 | 角色序號 = 1 的存活時長; 各命的存活時長 |
| 意外死亡 ≤ 30%、上限不被當死亡手段 | 死因、死前最後一次輸入距死亡秒數、死亡座標、死亡位置是否落在設計死亡點 |
| 玩家不會大量濫用靜止幽靈 | 錄影中零輸入總秒數、最長連續靜止秒數、死因 = 錄影上限 |
| 鉤爪判定寬度(整段騰空約 0.4 秒以上都可拉)與操作誤差 | 互動(鉤爪)的成功與否、鉤爪按下時幽靈已騰空秒數、幽靈循環相位 |
| 等相位時間約為半個循環 | 到達互動點到第一次成功互動的等待秒數、互動的相位 |
| 錯過一圈的成本 | 這條命經過幾次幽靈循環、存活時長 |
| 高度分層 | 最高到達高度、是否經過非預期路線、通關時用了幾名角色 |
| 重置預告是否足夠 | 循環重置時站在幽靈上而墜落的次數 |
| 需要點 1.5~2 秒停留窗 | 幽靈在需要點的停留秒數、角色 2/3 到達需要點時與幽靈的相位差 |
| 新手 2~4 輪、2~3 分鐘 | 跑了幾輪、這關總耗時 |
| 重來成本(重錄角色 3 約 15~25 秒、退回改角色 2 約 35~45 秒、整關約 50 秒) | 每次重來的種類與名次、各命存活時長、這關總耗時 |
| 超過 5 分鐘視為過難 | 是否放棄這關、放棄前耗時、這關總耗時 |
| 沒有關卡被少用角色跳過 | 通關時用了幾名角色 |
